# Gymnastics Landing Page

This project is a simple landing page for a gymnastics website. It is built using HTML and CSS to showcase the basic structure and styling of a web page.

## Features

- Responsive design
- Clean and modern layout
- Information about gymnastics classes and events
- Contact form for inquiries

## Technologies Used

- HTML5
- CSS3
